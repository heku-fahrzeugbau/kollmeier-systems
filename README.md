# Kollmeier Systems

Persönliche Website von Robin Kollmeier für CAD-Konstruktion, Automatisierung, 3D-Druck-Beratung und technische KI-Lösungen.

## Entwicklung

```sh
npm install
npm run dev
```

## Produktion

```sh
npm run build
npm run preview
```

Der statische Build wird in `dist/` erzeugt und kann bei IONOS bereitgestellt werden. Das Kontaktformular nutzt Web3Forms.
