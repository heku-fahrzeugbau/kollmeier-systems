# Kollmeier Systems

Persönliche Website von Robin Kollmeier für CAD-Konstruktion, Automatisierung, 3D-Druck-Beratung und technische KI-Lösungen.

## Entwicklung

```sh
npm install
npm run dev
```

## Produktion

```sh
npm run build
npm run preview
```

Der statische Build wird in `dist/` erzeugt. Deployment läuft über Vercel: ein Push auf `main` geht live, Branch-Pushes erzeugen ein Preview-Deployment. Das Kontaktformular nutzt Web3Forms.
